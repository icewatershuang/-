# 水哥拯救墨水屏（横屏版）

在老旧安卓墨水屏设备上常显日历、时间、提醒、新闻、天气，播放大量电台和本地音乐。

> 项目仓库：<https://github.com/icewatershuang/->
> 当前版本：**V3.3_760**（横屏版）

---

## ⚠️ 重要：安装后必须授予足够权限

这是本项目**最容易被忽略、也最容易导致功能异常**的一步。程序需要访问本地媒体文件与网络音频流，如果权限不足，**音乐播放（music）等功能会直接无法正常使用**，且通常不会给出明显报错。

请在安装完成后，按下面步骤逐项授权：

### Android 6.0 及以上（需运行时授权）

| 权限 | 用途 | 不授权的后果 |
| --- | --- | --- |
| **存储 / 文件与媒体**（`READ_EXTERNAL_STORAGE` / `READ_MEDIA_AUDIO`） | 读取设备上的本地音乐文件 | **本地音乐列表为空，无法播放** |
| **音频录制**（`RECORD_AUDIO`） | 部分电台/语音相关功能所需的音频通道 | 相关音频功能异常 |
| **麦克风**（`MICROPHONE`） | 同上（部分系统与录音权限合并显示） | 同上 |
| **网络访问**（`INTERNET`） | 在线电台、新闻、天气数据 | 电台无法加载、天气/新闻空白 |
| **通知**（`POST_NOTIFICATIONS`，Android 13+） | 常显提醒与通知栏信息 | 提醒不弹出 |
| **修改音频设置**（`MODIFY_AUDIO_SETTINGS`） | 音量与音频输出控制 | 音量调节失效 |
| **唤醒锁定 / 前台服务**（`WAKE_LOCK` / `FOREGROUND_SERVICE`） | 常显时保持运行、息屏后继续播放 | 息屏后程序被杀、音乐中断 |

**授权路径**：`设置 → 应用 → 水哥拯救墨水屏 → 权限`，把「存储 / 文件与媒体」「麦克风 / 音频」两项手动打开。

### Android 4.x ~ 5.x（安装时授权）

安装向导会一次性列出全部权限，**必须全部勾选同意**，否则安装后无法补授存储权限，音乐功能将永久不可用。

### 授权后仍不能播放音乐的排查顺序

1. 确认「存储 / 文件与媒体」权限已开 → 打开程序 → 进入音乐页，看列表是否出现本地文件；
2. 若列表为空，把音乐文件放到设备**根目录 `Music/`** 或程序提示的扫描目录下，再重启程序重新扫描；
3. 确认网络权限已开 → 在线电台才能正常加载；
4. 老设备（Android 4.0.x）若出现「应用未安装 / 解析包时出现问题」，请下载 **`KDashBoardL_V3.3_760.apk`**（v1 签名版），该版本针对老系统签名链做了兼容。

## V3.3_760 本次修复

相对 V3.2_759 解决的问题：

1. **主页左右各留 12px 白边**
   根因：`#topWrap` 是全屏横向容器的唯一子元素，内部 `.layout` 的左右 12px 被算进了总宽度。
   修复：给 `#topWrap` 加 `box-sizing: border-box; padding: 0 12px`，让 padding 吃在容器内部。

2. **设置页与次级清单可被上下拉动**
   根因：老旧 WebKit（Android 4.0.4 / WebKit 534.x）下 `scrollTop` 写入无效、`position: fixed` 容器不生成原生滚动条。
   修复：改用「裁剪盒 + `translateY` 夹层」方案，由 JS 直接写 `transform`，并在内层滚到头时把手势接力给外层。

## 技术要点

* **目标环境**：Android 4.0.4（API 14）老 WebKit 内核，`minSdkVersion=14`
* **包名**：`com.kindledash.landscape`
* **签名**：`keytool`（PKCS12 / SHA1withRSA）→ `zipalign -p 4` → `apksigner sign`
* **滚动方案**：裁剪盒固定高度 + 内层 `transform: translateY(-N)`，夹层在被渲染器冲掉后自动重新包裹
* **类名匹配**：白名单 + `cn.split(/\s+/)` 整词匹配，避免 `.radio-my-row` 被子串误命中
